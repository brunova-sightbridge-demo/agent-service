# IRS — Instructions for Form 8824: deferred exchange timing

Public source: https://www.irs.gov/instructions/i8824

The IRS instructions explain that a deferred exchange has separate deadlines. Replacement property generally must be identified within 45 days after the relinquished property is transferred. The replacement property generally must be received within 180 days after that transfer, or by the tax-return due date including extensions if earlier. The instructions also discuss how real-property status is determined and state that U.S. real property is not like-kind to foreign real property.

These are general rules; a qualified tax professional must assess an actual exchange and its dates.
